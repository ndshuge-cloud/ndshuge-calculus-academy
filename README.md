# 笛卡尔的普林斯顿微积分学院

以班纳《普林斯顿微积分读本》为蓝本的交互式微积分学习网页。

## 怎么用

直接访问本仓库的 GitHub Pages 网址，在浏览器里打开即可开始学习，无需下载、无需安装。

## 功能

- 28 周学习计划，勾选进度
- 30 章课程体系（章节陆续补全中）
- 即时批改的练习题
- 问答批改
- 学习足迹记录
- 徽章系统

## 技术说明

- 单文件 HTML（所有样式与脚本内嵌），无外部依赖
- 学习进度保存在各学习者自己的浏览器 localStorage 中，互不影响
- 侧边栏有「导出进度」「导入进度」按钮，可自助备份或迁移进度

## 内容版权

本网页为原创教学内容，以《普林斯顿微积分读本》（Adrian Banner 著）为参考蓝本编写。书籍原文不在本仓库内。
